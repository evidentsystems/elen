# elen

Efficient Lexicographic Encoding of Numbers (ELEN): text encodings of numbers whose
byte-wise lexicographic order matches numeric order, after Peter Seymour's paper
["Efficient Lexicographic Encoding of Numbers"](https://www.zanopha.com/docs/elen.pdf).
